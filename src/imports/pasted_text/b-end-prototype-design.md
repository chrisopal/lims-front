请为一个 B 端 Web 端产品设计一套高保真前端原型，产品名称可暂定为：

Composable AI-Native LIMS
或
Laboratory Operations Platform

这是一个“可组合、可配置、面向多行业场景的实验室管理与运营平台”，不是传统单一 LIMS。它既支持企业内部实验室，也支持第三方检测实验室，并且支持不同检测领域的配置，例如理化检测、食品检测、几何量检测、新能源检测、环境检测、核电检测等。

请设计成企业工作台风格的桌面端产品原型，重点体现：
1. 端到端实验室业务链路；
2. 场景配置能力；
3. 不同实验室模式（企业内部 / 第三方）；
4. 不同检测场景的流程、检测项、标准法规、方法、报告模板等可配置能力；
5. AI 能力嵌入业务流程，而不是单独做一个聊天机器人。

--------------------------------
一、整体设计风格要求
--------------------------------
整体风格：克制、扁平、统一、信息清楚的企业工作台。
不要做成营销官网，不要做成互联网炫酷风，不要大面积插画，不要玻璃拟态，不要渐变，不要光晕，不要厚重阴影。
采用浅色主题，桌面 Web 后台风格。

视觉要求：
- 单一蓝色体系 + 蓝灰中性色
- 页面画布：浅灰色
- 面板：白色
- 主交互色：品牌蓝 / 操作蓝
- 强调通过信息层级、布局、边框、间距来建立秩序
- 不要层层卡片嵌套
- 信息密度中高，适合专业业务人员
- 使用细边框和轻分隔线
- 普通正文 14px
- 控件圆角 4px
- 面板和弹窗圆角 6px
- 侧边栏宽度约 220px
- 顶栏高度约 48px
- 页面边距约 24px × 32px
- 图标线性、简洁、专业

颜色建议：
- 品牌蓝：#1677FF
- 可读交互文字蓝：#0966D9
- 主按钮背景：#0966D9
- 页面画布：#F5F7FA
- 面板背景：#FFFFFF
- 主文字：#0B1220
- 次级文字：#526075
- 边框：#D9DEE7
- 选中浅底：#EDF4FF
- 成功：#18794E
- 警告：#A9650A
- 危险：#C32F3F

框架要求：
- 左侧导航栏 + 顶栏 + 主内容区
- 不要为了“像后台”而增加无意义控件
- 所有页面都要保持统一的企业工作台风格
- 对专业工作面（如流程配置、报告模板设计、审核工作台）只统一外层色彩和布局，不破坏专业工作面本身的结构

--------------------------------
二、产品定位与核心概念
--------------------------------
这是一个可组合的实验室平台，支持以下组合能力：

1. Business Mode Pack（业务模式包）
- 企业内部实验室 Internal Lab
- 第三方检测实验室 Third-party Lab

2. Domain Pack（领域场景包）
- PhysChem 理化检测
- Food 食品检测
- Metrology 几何量 / 计量检测
- Environment 环境检测
- Battery / New Energy 新能源检测
- Nuclear 核电检测

3. Standard Pack（标准法规包）
- 按行业/领域加载不同法律法规、国家标准、行业标准、企业标准
- 支持版本化

4. Method Pack（检测方法包）
- 不同检测项目匹配不同方法与方法版本

5. Report Pack（报告模板包）
- 不同场景配置不同报告模板
- 支持正式报告、内部结果单、证书等

6. AI Skill Pack
- 标准智能匹配
- 委托解析
- 报告草稿生成
- 报告审核
- 结果异常识别
- SOP 助手
- 智能任务调度建议

请让整个原型清晰表达：
“系统不是写死一个流程，而是通过配置组合不同实验室业务模式、流程、检测项、标准方法、报告模板和 AI 能力，形成不同场景解决方案。”

--------------------------------
三、核心业务链路（端到端）
--------------------------------
请围绕以下主业务链进行页面设计：

需求/委托
→ 受理
→ 测试/检测策划
→ 资源配置
→ 样品或检测对象准备
→ 检测执行
→ 原始记录 / 结果处理
→ 技术审核
→ 报告/证书
→ 交付
→ 归档/售后

要体现：
- 第三方实验室更强调客户、报价、合同、委托、交付
- 企业内部实验室更强调内部申请、来源系统、检验任务、质量反馈
- 流程主干相似，但前后链路和字段配置不同

--------------------------------
六、业务内容与文案要求
--------------------------------
请使用真实的企业级中文文案，不要写“Lorem ipsum”。
尽量贴近专业实验室场景。
用词专业，但不要过于学术。
示例内容可包含：
- 食品：铅、镉、菌落总数、水分、蛋白质

法规和标准示例可使用：
- GB / ISO / ASTM / IEC / 企业标准 / 行业规范
- 食品标签法规
- 检测标准版本号
- 方法版本号

八、最终效果目标
--------------------------------
最终原型需要看起来像一个真正面向企业客户的、可产品化销售和研发落地的 LIMS / Laboratory Operations Platform，而不是普通后台管理系统。

1. 这是一套可组合的平台，不是单一写死流程的系统；
2. 它能支持不同实验室模式、不同检测场景、不同标准法规与报告体系；
3. AI 能力嵌入具体业务节点，如标准匹配、任务调度、报告生成、报告审核，而不是独立悬浮的聊天机器人。
