# 完整交互前端设计与实施计划

用户已确认以完整交互前端验收；仅浏览器模拟服务，不开发后端。

## ADR 001 — 在现有 Vue 产品上接通业务数据
保留 Vue 3、Element Plus、hash 路由和企业 UI。新增可替换的本地仓库边界，拒绝重写框架和仅补静态页面。场景发布产生复制快照，激活控制新委托可选范围，历史委托不随草稿更新。

## ADR 002 — 配置模型
代码注册的节点与 Renderer + 版本化业务资产 + 场景包。行业字段放入描述数据。寄样、采样回实验室、现场检测使用不同节点配置；现场零件不强制转为样品。模拟角色权限用于交互验证，不是服务器安全控制。

## ADR 003 — 本地运行边界
沿用受锁保护的 LocalRuntimeRepository，保留旧存储读取。配置与业务资产使用独立版本化仓库；发布时复制资产引用，运行时复制发布版本。浏览器存储失败、版本冲突和缺失资源必须可见。禁用任意代码求值。

## 实施任务
- [x] 场景：列表/创建/复制/编辑，配置字段与检测项绑定，流程节点增删排序，校验/发布/版本差异/激活；接通委托选择器。
- [x] 资产与平台：检测项、标准、方法、限值、表单、模板、设备、资质、实验室、组织、角色、设置、集成、AI 描述；搜索/新增/编辑/状态/导出及刷新恢复。
- [x] 运行：委托、对象/样品、任务、审核、报告、审计与工作台共用真实本地记录；审核退回、报告预览导出。
- [x] 示例：食品寄样、环境采样、内部几何量、现场几何量、新能源、高校。
- [x] 验证：严格运行域类型检查及回归测试、生产构建、真实浏览器页面操作、刷新恢复与六套示例业务闭环；检查 390/1366/1440/1920 视口。

## 文件边界
src/runtime/scenario-repository.ts 和 useScenarioRepository.ts：场景生命周期。
src/runtime/catalog-repository.ts 和 useCatalog.ts：资产/资源/管理配置。
src/runtime/local-runtime.ts 和 useLocalRuntime.ts：委托与作业。
src/views：保留各专业页面路由，逐项接入。

## 验收规则
不能仅弹出成功提示；每次写操作必须读回；发布后不可直接修改；停用后不再创建新委托；历史请求锁定版本；必填与状态转换校验；审核退回能重新提交；报告取自对应请求记录；导出文件能读取；无占位页与无行为的主操作。设备/AI/集成配置不宣称实际连接外部系统。
